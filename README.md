# Notes

App personal de notas (instalable en Android) de Daniel.

- La pantalla vive aquí y se publica con GitHub Pages.
- Los datos (notas, carpetas, fotos) quedan en Google Drive y se leen a través de una API en Google Apps Script protegida con clave.
- Ni la URL de la API ni la clave se guardan en este repositorio: la app las pide la primera vez y las guarda solo en el celular.
